:: 야디당 아윗자-빳짜야- 상카-라-, 상카-라빳짜야- 윈냐-낭.
°°yadidaṃ avijjāpaccayā saṅkhārā, saṅkhārapaccayā viññāṇaṃ.°°

:: **무명의법 조건으로 업의행위 생겨나며, 업의행위 조건으로 의식의법 생겨나네.**

:: 윈냐-나빳짜야- 나-마루-빵, 나-마루-빠빳짜야- 살라-야따낭.
°°viññāṇapaccayā nāmarūpaṃ, nāmarūpapaccayā saḷāyatanaṃ.°°

:: **의식의법 조건으로 정신물질 생겨나며, 정신물질 조건으로 육문의법 생겨나네.**

:: 살라-야따나빳짜야- 팟소-, 팟사빳짜야- 웨-다나-.
°°saḷāyatanapaccayā phasso, phassapaccayā vedanā.°°

:: **육문의법 조건으로 접촉의법 생겨나며, 접촉의법 조건으로 느낌의법 생겨나네.**
