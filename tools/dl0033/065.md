:: 우빠-다-나니로-다- 바와니로-도-, 바와니로-다- 자-띠니로-도-.
°°upādānanirodhā bhavanirodho, bhavanirodhā jātinirodho.°°

:: **취착의법 소멸하여 생을낳는 업이없고, 생을낳는 업이없어 태어남이 사라지네.**

:: 자-띠니로-다- 자라-마라낭, 소-까, 빠리데-와, 둑카, 도-마낫수빠-야-사- 니룻잔띠.
°°jātinirodhā jarāmaraṇaṃ soka parideva dukkha domanassupāyāsā nirujjhanti°°
에-와메-땃사 께-왈랏사 둑칵칸닷사 니로-도 호-띠.
°°evametassa kevalassa dukkhakkhandhassa nirodho hoti.°°

:: **태어남이 사라져서 늙음병듦 사라지며, 슬픔비탄 몸과마음 고통들이 사라지고,**
**극에달한 절망이란 마음고통 사라지네. 이와같이 고통낳는 조건들이 사라지네.**
