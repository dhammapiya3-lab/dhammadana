:: 스왁카-또- 바가와따- 담모-, 담망 나맛사-미.
°°svākkhāto bhagavatā dhammo, dhammaṃ namassāmi.°°

:: **처음중간 끝도좋고 열반까지 안내하는, 공덕높은 세존께서 잘설하신 높은법께,**
**공손하게 교만줄여  높은예경 올립니다.**
**(타종1배)**
