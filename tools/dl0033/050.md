## 오-와-다 빠-띠목카

:: °°Ovāda pātimokkha°°

:: "한때 부처님께서 제-따와나(Jetavana) 승원에서 머무셨을 때, 출현하셨던 모든 부처님들께서는
오-와-다 빠-띠목카(Ovāda Pātimokkha/훈계계목)를 어떻게 설하셨는지에 대해서
질문한 아-난다 존자에게 이와 같은 게송의 가르침으로 답하시었다."
(Dhammapada 183, 184, 185번 게송)
(*오-와-다 빠-띠목카 : 율장의 가르침이 형성되기 이전 포살일마다 훈계하셨던 모든 부처님들의 공통된 가르침)

:: 삽바빠-빳사 아까라낭, 꾸살랏사 우빠삼빠다-,
°°sabbapāpassa akaraṇaṃ, kusalassa upasampadā,°°
사찟따빠리요-다빠낭, 에-땅 붓다-나 사-사낭.
°°sacittapariyodapanaṃ, etaṃ buddhāna sāsanaṃ.°°

:: **모든종류 악행들을 행함없이 멀리함과, 모든종류 선행들을 계발하고 완성함과,**
**자기자신 지닌마음 청정하게 닦아나감, 출현하신 모든부처 가르침은 이와같네.**
