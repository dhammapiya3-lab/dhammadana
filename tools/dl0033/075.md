## 성불 찬탄게송

:: 아비세-까 가-타-
Abhiseka gāthā

:: 자얀또- 보-디야- 물-레-, 사꺄-낭 난디웃다노-,
°°jayanto bodhiyā mūle, sakyānaṃ nandivuḍḍhano,°°
에-와메-와 자요- 호-뚜, 자얏수 자야망갈레-!
°°evameva jayo hotu, jayassu jayamaṅgale!°°

:: **석가족의 자부심과 기쁨되신 부처님은, 보리상수 아래에서 모든번뇌 이기셨듯,**
**이와같이 그대들께 모든승리 함께하길! 승리자의 축연에서 그대들도 함께하길!**

:: 아빠라-지따빨랑께-, 시-세- 뿌투위뿍칼레-,
°°aparājitapallaṅke, sīse puthuvipukkhale,°°
아비세-께- 삽바붓다-낭, 악가빳또- 빠모-다띠.
°°abhiseke sabbabuddhānaṃ, aggapatto pamodati.°°
