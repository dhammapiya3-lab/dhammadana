:: 3)순관,역관
아눌로-마, 빠띨로-마
°°anuloma, paṭiloma°°

:: 이띠 이마스밍 사띠, 이당 호-띠. 이맛숩빠-다-, 이당 웁빳자띠.
°°Iti imasmiṃ sati, idaṃ hoti. imassuppādā, idaṃ uppajjati.°°

:: **이와같이 원인의법 분명하게 존재하니, 이와같은 결과의법 분명하게 존재하네.**
**이와같은 원인의법 생겨나는 이유로써, 이와같은 결과의법 분명하게 생겨나네.**

:: 이마스밍 아사띠, 이당 나 호-띠, 이맛사 니로-다- 이당 니룻자띠.
°°imasmiṃ asat, idaṃ na hoti. imassa nirodhā, idaṃ nirujjhati.°°

:: **이와같이 원인의법 존재하지 않음으로, 이와같은 결과의법 존재하지 않는다네.**
**이와같은 원인의법 소멸하는 이유로써, 이와같은 결과의법 소멸하여 사라지네.**
