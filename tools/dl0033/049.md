## 4. 약품에 대한 숙고

:: 빠띠상카- 요-니소- 길라-나빳짜야 베-삿자 빠릭카-랑 빠띠세-와-미.
°°paṭisaṅkhā yoniso gilānapaccaya bhesajja parikkhāraṁ paṭisevāmi.°°
야-와데-와 웁빤나-낭 웨이야-바-디까-낭
°°yāvadeva uppannānaṁ veyyābādhikānaṁ°°
웨-다나-낭 빠띠가-따-야 아뱌-빳자 빠라마따-야.
°°vedanānaṁ paṭighātāya abyābajjha paramatāya.°°

:: **여법함을 조건으로 지혜로써 숙고하며,**
**병든자의 필수품인 약품들을 의지하리.**
**이미생긴 질병상처 고통들을 제거하며,**
**고통없이 건강하게 출가의삶 살기위해,**
**약이라는 소유물을 의지하여 사용하리.**
