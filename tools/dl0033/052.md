## 다섯 가지 공양올림

:: 등(초)공양
빠디-빠 뿌-자-
°°Padīpa pūjā°°

:: 아라하따-디 나와구네-히 사만나-가땅, 나-탕 붓당 웃딧사 쩨-띠얏사,
°°arahatādi navaguṇehi samannāgataṃ, nāthaṃ buddhaṃ uddissa cetiyassa,°°

:: 안다까-랑 위나-사깡 이망 디-빠잘-랑 삭깟짱 데-미 뿌-제-미.
°°andhakāraṃ vināsakaṃ imaṃ dīpajālaṃ sakkaccaṃ demi pūjemi.°°

:: **아라한등 아홉가지 공덕들로 구족하신 인간들과 천인들의 의지처가 되어주신,**
**존귀하신 부처님을 마음으로 향하고서 사리경전 불상유물 높게모신 불탑에게,**
**무명이란 어두움을 몰아내는 밝은등불 공손하게 보시하여 높은예경 올립니다.**
