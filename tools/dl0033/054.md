:: 물공양
우다까 뿌-자-
°°Udaka pūjā°°

:: 아라하따-디 나와구네-히 사만나-가땅, 나-탕 붓당 웃딧사 쩨-띠얏사,
°°arahatādi navaguṇehi samannāgataṃ, nāthaṃ buddhaṃ uddissa cetiyassa,°°

:: 숫다 시-딸라 빠산낭 이망 빠-니-야빠리보-자니-양 삭깟짱 데-미 뿌-제-미.
°°suddha-sītala-pasannaṃ maṃ pānīya-paribhojanīyaṃ sakkaccaṃ demi pūjemi.°°

:: **아라한등 아홉가지 공덕들로 구족하신 인간들과 천인들의 의지처가 되어주신,**
**존귀하신 부처님을 마음으로 향하고서 사리경전 불상유물 높게모신 불탑에게,**
**깨끗하고 시원하며 청정하게 마련해둔 마실물과 사용할물 이와같은 물공양을,**
**공손하게 보시하여 높은예경 올립니다.**
