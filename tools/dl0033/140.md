:: 14.
에-따-디사-니 까뜨와-나, 삽밧타 마빠라-지따-,
°°etādisāni katvāna, sabbattha maparājitā,°°
삽밧타 솟팅 갓찬띠, 땅 떼-상 망갈라뭇따만띠.
°°sabbattha sotthiṃ gacchanti, taṃ tesaṃ maṅgalamuttamanti.°°

:: **이와같은 삼십팔행 축복의법 행함으로,**
**모든원수 이겨내고 어디서나 행복하니,**
**이와같이 행함들이 높고귀한 축복이네.**

:: 망갈라숫땅 닛티땅.
°°maṅgalasuttaṃ niṭṭhitaṃ.°°
**축복경 마침.**
