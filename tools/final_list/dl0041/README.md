# 최종 교정 목록 만들기 — DL-0041 에 쓴 작업 스크립트 (2026-11-22)

다음 책에서 참고해 고쳐 쓰는 본보기. 경로(/tmp/d41orig.json, /tmp/d41fin/…)와 책 ID 가 박혀 있으니 바꿔 쓴다.

1. `git show <교정 전 커밋>:content/texts/<ID>.json > /tmp/orig.json` — 교정 전 본문
2. extract.py — 교정 목록을 한 줄씩 다시 적용, 결과가 사이트 본문과 같은지 확인
3. spans.py — 문단마다 바뀐 자리를 따라가며 한 자리를 여러 번 고친 곳을 한 곳(처음 글 → 마지막 글)으로 묶음 (build.py 의 cat()·src() 로 묶음·근거)
4. rows_make.py — 단락 옮기기 등 손으로 더할 줄, 쪽 이름 다듬기, 정렬
5. xlsx.py — 엑셀(한 곳씩 + 묶음별 합계 시트) / md.py — Docs 문서에 넣을 묶음별 표(같은 고침은 한 줄로)
