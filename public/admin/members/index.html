회원 자료실 관리

여기 올린 파일은 회원 전용 창고에 들어가고, 허락받은 분이 로그인해야만 볼 수 있습니다. 공개 파일 저장소(files.dhammadana.kr)와는 따로 떨어져 있습니다.
들어올 사람(이메일) 허락·빼기는 Cloudflare 화면의 Access 정책에서 합니다.

관리자 열쇠

관리자 화면에 로그인할 때 쓴 GitHub 열쇠(github_pat_…)를 한 번 넣어 주세요. 이 브라우저에만 저장됩니다.

1. 폴더 이름

자료를 묶을 이름입니다. 예: 수행 모임 자료, 번역 원고. 비워 두면 '자료'에 들어갑니다.

2. 파일 올리기

여기를 눌러 파일을 고르거나
파일을 끌어다 놓으세요 (여러 개 가능)
PDF·EPUB·한글·워드·mp3·사진 등, 한 파일 100MB까지

올라와 있는 자료

지울 파일을 골라 '고른 파일 지우기'를 누르세요. 지운 파일은 되살릴 수 없습니다.
