# 운영 안내 (혼자 운영하기)

## 1. 평소에 하는 일 — 관리자 화면
1. https://dhammadana.kr/admin 에 들어가 GitHub로 로그인합니다.
2. 왼쪽에서 고칠 곳을 고릅니다: **책 / 소식 / 글 페이지 / 목록**.
3. 고친 뒤 **저장(Save)** 을 누르면, 1~2분 뒤 사이트에 반영됩니다.

| 하고 싶은 일 | 가는 곳 |
|---|---|
| 새 소식 올리기 (블로그·카페 글 붙여넣기) | 소식 → 새로 만들기 |
| 책 정보·소개 고치기 | 책 → 책 고르기 |
| 새 주제·스승 더하기 | 목록 → 주제 / 스승 |
| 협력 단체 더하기 | 목록 → 자료 제공처·협력 단체 (협력 단체로 보이기 켜기) |
| 검색 표기 더하기 (예: 멧따 = 메따) | 목록 → 표기 사전 |
| 법문 재생목록 더하기 | 목록 → 법문 재생목록 (팟빵 RSS 주소) |

## 2. 새 책 올리기 (PDF가 있을 때)
내 컴퓨터의 Claude Code에게 이렇게 말하면 됩니다:
> "이 PDF를 도서관 책으로 올려줘. 자료번호 DL-0008, 초판이야."

Claude가 하는 일: 쪽 그림·본문 글·목차 만들기 → 깨진 빨리어 글자 점검 → R2에 올리기 → 책 정보에 '온라인 읽기' 켜기 → 사이트에 반영.

## 3. 판이 바뀌었을 때
책 → 판 더하기 → 새 판에 '최신판' 켜고, 이전 판의 '최신판'은 끕니다. 이전 판은 지우지 않습니다(보관).

- 사이트(Cloudflare Pages)·관리자 화면: 무료
